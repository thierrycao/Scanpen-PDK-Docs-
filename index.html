1. 工程定位

Scanpen 是基于 ARCS PDK 的智能扫描笔方案，当前主业务运行在 CP 侧，集成扫描取像、OCR、语言检测、中英互译、TTS 播报、触摸屏 UI、USB CDC/MSC、经典蓝牙耳机、OTA 和基础网络能力。最新版本把扫描服务和电源开机策略前移到 SYS_INIT 阶段，main() 只保留业务入口、UI 和常驻喂狗。

  • 应用入口位于 apps/scanpen/main.c，当前流程为打印版本/开机原因、喂狗、按需 cpp_init()、初始化扫描键、分词资源和 LVGL/AuraUI。
  • scan_server_init() 已通过 SYS_INIT(scan_server_init, SYS_INIT_LEVEL_PRE_APPLICATION, 45) 自动初始化，不再由 main() 显式调用。
  • scanpen_power_boot_early_init() 在 SYS_INIT_LEVEL_PRE_APPLICATION, 20 阶段识别扫描键、电源键、语音键和 USB MSC handoff，并决定是否保持 PWR_LOCK。
  • 跨模块通信通过 pdk_msg 统一发布/订阅，扫描业务使用 PDK_DOMAIN_SCAN 消息域；UI 返回键使用应用私有消息 PDK_MSG_UI_BACK。
  • UI 页面通过 PDK 消息接收扫描状态，最新实现使用 FreeRTOS queue + LVGL timer 把异步事件安全切回 UI 线程，而不是在 PDK 回调中直接操作界面。
  • 资源和固件按 apps/scanpen/res/partitions.yaml 管理，当前支持 Flash2 独立资源 scanpen_flash2.bin、eMMC 分词资源和 OTA 包升级。

2.5 OTA 升级

Scanpen 复用 PDK 通用 OTA 架构：APP 侧提交 OTA request，boot/recovery 读取升级包、校验 manifest、解包并写入目标分区。Scanpen 的打包策略位于 apps/scanpen/res/ota_package.json，当前默认 OTA 源为 TF/eMMC FAT 文件。

默认 OTA 源TF / eMMC FATCONFIG_APP_OTA_SOURCE_TF=y 时从文件系统读取升级包。

提交给 boot 的路径download/update.txzboot/recovery 使用相对路径读取。

不打包项boot、eq_param、easyflash、scan_calib、vendor_storage、nvds、emmc_fsboot、运行时/工厂参数和 FAT32 文件系统默认不进入 OTA 包，避免覆盖设备个体数据。

8.1 LVGL 基础

LVGL 是嵌入式设备常用的轻量 GUI 库，核心对象是 lv_obj_t。按钮、标签、图片、列表等控件都是 LVGL 对象，布局、样式、事件都围绕对象树组织。

概念Scanpen 中的用法开发要点
对象树lv_obj_create(parent) 创建容器；lv_label_create()、lv_image_create() 创建子控件。父对象销毁时子对象随之销毁，避免手动释放 LVGL 子控件。
样式lv_obj_set_style_bg_color()、lv_obj_set_style_text_color()、lv_obj_set_style_radius()。样式可继承，字体和颜色建议在页面根容器或 Theme 中统一设置。
布局Launcher 使用横向 flex；扫描页使用纵向 flex；文本区域使用 LV_LABEL_LONG_WRAP。小屏 320x170 上要优先考虑滚动、换行和触摸区域。
事件lv_obj_add_event_cb(obj, cb, LV_EVENT_CLICKED, user_data)。事件回调在 LVGL 线程执行，可直接操作 UI。
异步切线程lv_async_call(cb, data) 或 queue + lv_timer_create()。PDK 消息回调不在 LVGL 线程，必须切回 UI 线程；扫描页当前采用 queue + timer。
定时器lv_timer_create() 用于状态短暂显示后清空。页面销毁时删除页面持有的 timer。

12. RTC 定时闹钟

12.3 休眠、唤醒与时间连续性

14. 扩展开发建议

  • 新增结果消费者：订阅 PDK_MSG_SCAN_OCR_RESULT 和 PDK_MSG_SCAN_TRANSLATION_RESULT，复制字符串后在自己的任务处理。
  • 新增扫描触发源：不要直接调用内部状态机函数，统一发布 PDK_MSG_SCAN_START、PDK_MSG_SCAN_STOP 或 PDK_MSG_SCAN_ABORT。
  • 新增 UI 页面：页面生命周期内成对调用 pdk_msg_sub / pdk_msg_unsub，所有 LVGL 操作切回 UI 线程。
  • 新增校准能力：优先扩展 scan_calib.h 的命令枚举与 scan_server_handle_calib_usb_cmd()，并同步更新 PC 工具协议文档。
  • 新增应用私有消息：使用 PDK_DOMAIN_APPLICATION 或新增独立 domain，避免占用已有事件范围。

16. 调试排障

  • 实时日志：串口波特率 921600，或使用 timeout 10 adb shell "" 2>&1 抓取运行日志。
  • 扫描无结果：先用 tools/scan_adjust_tool 查看摄像头图像，排查排线、镜头、亮度、裁切坐标和扫描速度。
  • UI 不刷新：确认是否订阅了正确消息，并检查是否在 LVGL 线程执行界面更新。
  • 多行扫描过早结束：通过 scan_server_set_multiline_timeout() 调大等待窗口。
  • 摄像头接口冲突：直接取帧前确认不在正常扫描或校准实时流状态。
